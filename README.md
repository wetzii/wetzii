# Hi, I'm Alexander

Student at **HTL Leoben**, Austria. I write Java on purpose, SQL out of necessity and VBA against my will.

I like building things end to end — from database schema to UI, from PCB to firmware, from a fresh Arch install to a fully riced desktop. Most of what I know I learned by breaking it first.

> *One day I want to earn money. Until then, I write code.*

## What I'm working on

- Software engineering & databases at HTL Leoben
- Building the website for **Subeme**, a hobby film club (yes, there is lore)
- Keeping my Hyprland setup reproducible, so the next wiped drive costs me minutes instead of a weekend
